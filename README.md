# Next.js Auth 2FA Admin Dashboard

A comprehensive Next.js application with Two-Factor Authentication (2FA), user management, and admin dashboard.

## Features

- ✅ User Login with Email & Password
- ✅ Two-Factor Authentication (2FA)
- ✅ Admin Dashboard for User Management
- ✅ Create Users (Admin Only - No Self Registration)
- ✅ Role-Based Access Control
- ✅ Ant Design UI Components
- ✅ Modern & Responsive Design

## Tech Stack

- **Frontend:** Next.js 14, React, Ant Design (antd)
- **Backend:** Next.js API Routes
- **Database:** MySQL (as per schema provided)
- **Authentication:** JWT + 2FA (TOTP)
- **Styling:** Tailwind CSS + Ant Design
